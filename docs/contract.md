# 数据与交互契约

共享 JSON [夹具](fixtures/) 约束 Kotlin 与 TypeScript 的模型和边界。

## 来源、搜索与 QX

- Luna 配置仅保留名称含 `🎬`、无 `_comment` 键且 API 非空的来源。同一 API 取首项，界面隐藏筛选用 emoji。显式配置优先，远程失败可回退本地配置。
- MacCMS 的 `code` 必须精确表示整数 1，ID 必须是正整数。详情响应必须包含所请求的 ID。保留无关查询参数及 `url=` 代理包装，编码非 ASCII 链接时保留现有转义和加号。
- 播放与下载按 `$$$` 分线路、`#` 分集，首个 `$` 拆名称和 URL。按原组位置对齐 `*_from`，再去空组。线路 ID 保留原组位置，空集名仍可播放和续播。
- 聚合先归一标题及年份，按保守规则隔离缺年份、空标题或信息冲突的记录。展示保留原文字。增量响应只追加新卡片、合并旧卡片，保持已出现的顺序、焦点和用户在搜索期间更新的播放记录。资源按配置顺序。CLI 只输出最终结果。
- CLI 的 `--config` 置于子命令之前。search/fetch 输出 JSON。部分来源失败时继续；搜索全部失败时报错。退出码 0 表示成功或管道关闭，1 表示业务错误，2 表示参数错误。
- 普通播放把原始集链接交给播放器。搜索和详情请求可重试。QX 独立解析静态 HTML、重定向和 HLS，以每条线路的首集为样本，收集清单中显式列出的域名。以 `; ` 注释标出 API、播放/下载及 M3U8 等分组。扫描无阶段截止时间，单次连接与读取保留超时。扫描不完整时保留已发现的规则，诊断走 stderr。

## 展示与持久化

- 聚合结果和「继续观看」共享作品卡片资料与优先海报。优先沿用保存的展示资料及成功加载的海报，再尝试最先完成聚合的来源和配置内候选。详情封面始终限当前资源。切换资源时保留上一份文字资料，等待期间停用播放。
- 详情默认资源依次为本作品上次成功播放的可用来源、推荐范围内全局最近成功播放的来源、本作品的推荐来源和其他可用来源。「无广告」表示已验收样本未发现独立博彩插播。关闭去广告时，只有这类来源参与推荐优先级。海报不参与选择。
- 实际播放来源、线路和集名独立于展示资料。每集位置按作品、资源站、来源作品 ID、线路、集名和零基集序存储。续播只恢复同一条记录。自然完播后续播位置归零，最近播放记为 100%。播放回调绑定原会话，迟到回调不能覆盖新会话。历史与偏好独立于缓存，持久化通过序列化的增删操作完成。
- 搜索只缓存完整结果。失败可重试，切换或离开后取消预取并丢弃迟到响应。豆瓣当前分类按上游完整分页，后台预取避开可见请求；Web 可回退快照。Android TV 请求豆瓣封面需共用 User-Agent 和 `https://m.douban.com/` Referer。
- TV 原生焦点优先。列表增量和切源不抢焦点，返回待目标卡片挂载再恢复位置。遥控返回在抬键时消费，以免同一按键传到目标页面。播放退后台后保留主动暂停状态。

## 播放与弹幕

- 自动下一集、作品级倍速记忆和去广告默认开启。只在自然结束后沿同源同线路播放下一集。失败、手动切换及退出均不得触发自动下一集。Web 另记忆全局音量和静音。
- 去广告只改写可安全处理的 HLS VOD，保留分片和密钥直连。主清单登记视频变体，按播放器请求过滤对应的媒体清单。独立音频和引用外置音轨的变体保留原样。重写保留初始化分片，媒体字节范围按原清单换算成显式偏移。续播存原始媒体时间，恢复时转换到有效时间。弹幕按播放器当前时钟渲染，已过滤的时间禁止再次扣减。暂停、缓冲冻结时钟，Seek 重建活动窗口。CUE、路径词、断点和重复本身不足以判定博彩插播。
- 自动弹幕与手动选择共用当前播放会话。手动选择剧集时才请求该轨道。成功的手动选择按 API、作品、资源及分集保存，自动结果不覆盖手动偏好。关闭弹幕保留已加载轨道，新会话取消旧请求。
- Kotlin 与 TypeScript 共用 [弹幕配置](../shared/danmaku-selection.json) 与 [匹配夹具](fixtures/danmaku-matching.sample.json)。先匹配作品，再在作品和来源内匹配分集。标题优先于服务的季分组，明确的季、集、日期和类型冲突不匹配，歧义交给手动选择。平台优先级独立于文本匹配，同组轨道兼容且数量至少翻倍才替换。

- 双端只绘制右到左的滚动弹幕。共享 8 秒生命周期、画面上方 1/5、贪心轨道及入场和离场两端的间距检查。空窗按媒体时钟唤醒，跳转后从二分定位的历史窗口重建。
