# 来源与博彩插播验收

## 推荐资源维护

在默认来源配置的条目中维护推荐状态，取值见[跨端契约](../contract.md#展示与持久化)。推荐依据为广告抽样结论（已验证可去广告或抽样未发现博彩插播），以及近期抽测的搜索、详情、媒体清单与连续分片访问成功率、播放稳定性和速度。复查首片和后续分片的耗时与媒体时长，并结合已有实播或解码记录判断稳定性。证据不足或失去基本可用性时移除推荐字段。记录样本范围、失败与耗时，见[策略验证记录](../../experiments/hls-ad/strategy-verification.md#来源可用性抽测)。

## 博彩插播验收口径

只统计打断剧情的独立博彩广告。连续播出的同一段算一次。非博彩品牌插播、正片滚动字、角标和水印不计。以**原始未过滤媒体**为分母。抽样先确定来源、线路、作品和集数，纳入未参与调规则的样本。同一媒体的镜像可分别验播放，汇总去广告率时只计一次。

1. 取得同一份原始 HLS 清单及完整媒体，在本机解码全轨。按分片保存音频偏移与原始清单时间的对应关系，保留无声、缺失或解码失败的区间。用多语言模型转写中文样本，非中文按实际语种设置。

   ```sh
   whisperkit-cli transcribe --audio-path original.wav --language zh --report --report-path reports
   ```

2. 用带时间戳的转写定位疑点，结合原画面和接缝前后剧情标注每段博彩广告的开始和结束。另核对全部拟删除区间及画面疑点。转写为空或未命中只说明未识别到口播。未检查的画面、无口播和解码失败区间需要标注，不能作为无广告证据。
3. 对同一原始清单跑生产过滤器。将删除区间和广告标注对齐到原始时间，复核过滤版接缝，确认广告的声音和画面均已移除，并检查有没有删掉正片或非目标内容。
4. **段数消除率 = 完整移除的博彩插播段数 ÷ 原始媒体确认的博彩插播段数 × 100%。** 分母包含漏删和只删一部分的段。可另报时长消除率，即删除区间与标注区间的交集时长 ÷ 确认广告总时长。同一时间段不重复计入。误删段数及时长单列。

按源报告分子、分母、检查范围、失败样本和误删。完成检查但未检出博彩插播时标「无分母」，获取或复核不完整时标「覆盖不完整」。仅对已核实的样本使用 100%，不可外推到全站。真源清单、带签名链接、媒体和转写留在本机。


## 实现边界

Media3 数据源和 hls.js 的 Loader 使用同一份 [HLS 通用策略](../../shared/hls-heuristics.json)。所有来源共用这套策略。候选组按断点、分片时长、归一化路径和重复指纹匹配。归一化将相对路径按媒体清单目录解析，去除协议、域名、端口、Query 和 Fragment。重复指纹比较分片路径及解析后的 ByteRange 偏移、长度。写回清单时沿用原始 URI。

过滤只处理已有的可安全重写的视频清单响应。时间轴和回退条件见 [跨端契约](../contract.md#播放与弹幕)。资源站、线路、作品、命中数和真源复核结果见 [策略验证记录](../../experiments/hls-ad/strategy-verification.md)，只供离线取证。
