# Android TV 弹幕

生产路径为 `PlayerScreen → DanmakuState / DanmakuPlayback → DanmakuClient`，Media3负责播放，单Canvas负责绘制。没有新增服务、数据库或识别模型。

## 使用与匹配

弹幕按钮在倍速右侧，菜单为开关、提前1秒、延后1秒、当前累计偏移、选择弹幕。时间校准只在快捷菜单提供。选择弹窗保留作品搜索、来源、剧集及次级API地址配置；输入框确认后编辑；未编辑时方向键用于导航，完成编辑后不清空焦点。来源使用逐项惰性列表，弹窗遵守48dp/28dp电视安全边距。地址必须单独保存，草稿不参与搜索；保存后重新匹配当前作品，API失败不影响视频。

手动偏好按服务地址＋workId＋site保存animeId，不区分线路/集数；只有成功加载当前集有效滚动评论后才保存。自动匹配、回退和替换不改写偏好。开关按播放进度的作品/资源站/线路/集数粒度保存，偏移限当前会话。

优先有效手动偏好，否则匹配标题、季度、年份和语义集号，再顺序探测爱奇艺、优酷、腾讯、芒果及其他来源。平台顺序不代表发行平台。首份有效评论立即显示；新来源mode 1数量达到当前两倍，且参考时长差不超过max(30秒,2%)时替换。缺集、空评论、失败继续回退；最多12个业务API调用/60秒，每候选20秒，最多缓存三份track。429停止本轮。

关闭只取消正在进行的自动匹配/比较，不清空来源和评论；再次开启有数据则直接恢复，无数据则重新匹配。手动选源/选集会取消自动优选，但其显式请求不会因开关而误取消。切播放会话或API服务取消旧请求，退出会话取消全部请求。只有一个请求Job。

## 绘制与时间轴

活动弹幕调用`postInvalidateOnAnimation()`，随设备刷新绘制，不设置固定FPS或降频控制。暂停/缓冲停止连续绘制，空窗按下一条评论时间及Media3倍速定时唤醒，关闭/释放取消唤醒。

完整评论保留；已排序游标只处理当前窗口，Seek后二分定位。实际画面上方1/4、最多四轨/12条；按真实文字宽度、入场距离和离场前追尾条件接纳条目，拥挤时跳过本窗口放不下的评论，不做全片数量截断。文字宽度缓存256项，不逐帧扫描、排序或测量全部评论。

位置取Media3真实时间。过滤后的播放时间已经去掉广告，不再扣广告；有已确认参考映射时转换，否则使用播放时间加一次手动偏移。参考时长接近不保证剧情版本一致，固定偏移不能修复中途剪辑差异。

## 验证入口与调查

日常执行Core JVM和Android单元测试及APK编译。保留匹配/回退、2倍替换、偏好范围、取消/恢复、429、服务变化测试，以及遥控器和真实Media3的暂停/Seek/倍速/空窗回归。

`LiveDanmakuPlaybackTest`是按需实网入口：显式传入`media_url`、`next_media_url`、`media_site`、`work_title`、`danmu_url`、`danmu_title_id`、`danmu_episode_id`。无参数跳过，不作为日常修改的强制项。真实媒体、令牌和评论只留本机；不再维护旧限帧策略的性能对照测试。

保留[三部作品调查原始统计](../../experiments/danmaku/survey-2026-11-17.json)及同目录样本和离线复现工具：2026-11-17快照中，嫁金钗两入口18,889条但均为同一优酷内容；逐玉腾讯42,288条、爱奇艺13,381条，约3.16倍；后会友期正片23,620条，没有第二个可比来源。数据会变化、重复入口不能当独立平台证据，调查未设置DANMU_LIMIT。

四源去广告保持原实现。[24份清单统计](../../experiments/hls-ad/four-source-current-2026-11-16.json)记录58组已确认素材、1117.656秒；该样本结果不代表全站覆盖率。[原真实联合播放证据](../../experiments/hls-ad/android-danmaku-playback-2026-11-16.json)及独立HLS研究继续保留，未因清理FPS实验而删除。

当前重点来源及播放验收范围见[Android TV重点来源](android-tv-sources.md)。

已知验收限制：Android 14 TV模拟器默认960×540dp下遥控器、弹幕及真实播放回归通过；640×360dp配合系统字体1.3倍时，打开选择弹窗的Compose空闲检测超时，修改前的弹窗同样可复现。该组合未通过，不能将默认尺寸结果外推。未保留对此无效的固定高度或确认键试验。实体电视音画和长时间播放仍需人工验收。
