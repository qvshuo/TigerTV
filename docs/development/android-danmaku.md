# Android TV 去广告与真实弹幕闭环

本页保留先前去广告闭环记录；最新弹幕自动匹配、偏好、交互和性能验证见 [2026-11-17 记录](android-danmaku-matching.md)。

此前基于 main `962b149`。本轮只开发 Android TV；未修改 macOS、来源配置或播放内核，未新增服务、数据库或运行依赖。

## 使用

此前测试部署及媒体/模型缓存已清理，用户随后手动重新部署的服务已通过接口复测。以下完整播放记录来自先前验收；当前界面与开关行为按本页使用说明及细节回归记录为准。

播放控制中弹幕位于倍速右侧，使用同款按钮/菜单。快捷菜单为关闭/开启弹幕、提前 1 秒、延后 1 秒、不可聚焦的当前偏移、选择弹幕；关闭后使用斜线弹幕图标，按钮文字仍为“弹幕”。设置居中，返回关闭；输入框仅聚焦不弹键盘，确认才编辑。搜索结果采用详情页同款选择芯片。服务配置后后台匹配，优先复用当前服务/作品/资源站的手动作品选择，按语义集号自动选集；自动匹配不保存偏好；可手动改选。默认开启，开关按作品/资源站/线路/集数保存，与播放进度的身份粒度一致；偏移限当前会话。

支持普通从右向左弹幕、限制在实际视频画面上方1/4，最多四轨/12条同时显示、中文/英文/数字及系统字体支持的表情，默认24sp和黑色描边。延后/提前每次1秒，立即生效。不开启时停止连续绘制；没有数据或API失败不影响视频。

**分母仅是已确认素材在这些清单中的出现，不是全部库存、整集逐帧审查或通用广告覆盖率。目标仍是100%；未检查内容不能当作无广告。** 本轮没有发现需要新增登记的已确认素材，因此没有为了“新增规则”扩大匹配范围。正常剧情抽查与保留URI顺序检查中，发现的误删为0；不是对所有剧情内容的绝对保证。剧情烧录横幅仍保留，无法通过删除独立分片去除。

先应用规则，再检查剩余小组与目录：每份过滤后都只剩一个普通媒体目录。魔都《逐玉》《长安》存在共224个保留的短结构组（普通媒体频繁加 discontinuity），未逐组看完；额外取六片/21.6秒窗口，画面是片头制作名单，不能按 discontinuity 删除。离线 tiny ASR 对片头音乐返回的短句不作为广告判断证据。已有真实广告和前后剧情证据继续复用，当前规则没有把未知目录或时长当成广告。

动态复取相较上一轮：爱奇艺6/6、360 6/6、魔都2/6清单原文变化，暴风0/6变化；**四源24份过滤后保留的URI顺序均与旧样本一致**。匹配当前完整URI组和时长，未复用历史广告时间。相同URI被源站替换成等时长内容仍是轻量规则的固有限制，不是内容哈希验证。

360 显式 IV AES-128 / NONE 切换保持原有支持；不支持的结构回退。魔都动漫已从正式规则与Android入口移除，新增回归证明即使候选匹配也不调用过滤器；它的普通播放和用户配置保留，历史共享素材研究保留。

四源都再次通过真实CDN Media3测试：从当前识别区间选取所有非尾部接缝，验证跨边界进度、音视频输出、暂停、倍速和时间映射。尾部删除不虚构后续剧情。

## 真实弹幕和同步

生产路径：`PlayerScreen → DanmakuPlayback/DanmakuState → Repository → CoreService.danmakuClient → DanmakuClient`。复用Core既有HTTP客户端，搜索/选集/评论解析在IO线程，不阻塞视频启动。

`DanmakuView` 是一个Android Canvas绘制循环，按Media3真实时间定位。排序数据配合游标，只消费新到期评论；Seek或偏移变化时二分定位最近8秒窗口，活动评论上限12，不为每条评论启动任务，不逐帧遍历完整评论。

过滤后播放器时间已经是有效播放时间，不再次扣广告。现有 `MediaTimeline.effectiveToReference` 有已确认映射时优先使用；否则按实际播放时间加用户偏移。固定偏移不等于自动剧情校准，不能自动消除中途残留广告、删减或速度差异。无共同剧情锚点时，不能宣称参考版本已一致。

实际 Android 14 TV arm64 模拟器中，生产 `PlayerScreen` 联合播放：

| 实际作品 | 弹幕参考来源 | 第1集实际加载/滚动评论 | 真实视频 |
|---|---|---:|---|
| 嫁金钗 |youku|18,939|暴风第1集，随后切真实第2集|
| 逐玉 |tencent|42,283|暴风第1集，随后切真实第2集|

服务数据随请求变化，早期约18,905条不是客户端硬编码目标。测试只注入目录名称/剧集地址元数据，**媒体、第二集和弹幕均真实联网获取**，没有用测试弹幕替代真实评论。

两个作品均通过：手动搜索和选集、实际画面滚动、暂停冻结、实际Seek缓冲期间冻结、Seek重建、1.5倍速、暂停时+1秒偏移即时生效、关闭停止绘制、切集清空、故意请求不存在API路径后视频继续播放。顶部弹幕入口使用真实方向键进入，并非直接设置其焦点。弹幕作品/集数按钮用原生TV焦点和确认键操作。

各做一分钟连续弹幕/视频采样：嫁金钗PSS 107,201–157,245KiB，逐玉169,556–184,794KiB，均观察到回收/波动；两段视频解码丢帧增量均0。是整个App PSS，不是弹幕独占内存、UI帧率或严格峰值；一分钟不能证明长期无泄漏，也未做真机硬件性能结论。

实际结果：[播放及性能证据](../../experiments/hls-ad/android-danmaku-playback-2026-11-16.json)。私有媒体、日志和开发阶段画面在 `/tmp/tigertv-source-audit/`；不提交原始URL、令牌或媒体。

## 代码与必要验收

- Android：`DanmakuPlayback.kt`（选择/校准）、`DanmakuState.kt`（可取消请求）、`DanmakuView.kt`（单绘制循环）、`PlayerScreen.kt` / `PlaybackControls.kt`（入口与焦点）。
- Core/适配：仅增加既有弹幕客户端的工厂转接；继续复用 `MediaTimeline` 和 HLS 过滤器，未增加第二套业务解析或时间轴。
- 正式支持收敛：`ModuAdRule.kt`、`HlsAdDataSource.kt`；来源配置未变。
- 关键测试：`LiveDanmakuPlaybackTest`、`HlsAdDataSourceTest`；原有遥控器暂停/Seek/倍速/分层返回回归。

Core JVM 71项、Android单元测试39项通过；四项Android HLS测试及一项原有遥控器回归通过。四源真实CDN测试4/4、两作品完整弹幕联合测试2/2通过，正常包名APK构建成功。所有模拟器实验使用隔离 `.adprobe` 包，临时构建修改已恢复，未覆盖原应用。

仍需人工验收的只有本轮无法自动判定的部分：真实剧情语义对齐、主观音画质量、电视真机和长时连续播放。当前没有以这些未验收项冒充通过；也没有阻塞弹幕可用闭环的新崩溃或已确认剧情误删。尚未发布。

细节回归：自动选集且保留关闭意图的单元测试通过；模拟器验证快捷菜单顺序、倍速右侧焦点、逐集关闭状态恢复、输入框聚焦不弹键盘/确认后可编辑，以及原有暂停/Seek/倍速/返回操作。

默认服务输入值为 `https://danmu-api.253520.xyz`，保留用户已保存的地址；可在后面追加 `/自己的密钥`。默认1倍速下弹幕约8秒过屏，随媒体倍速推进，轨道拥挤时跳过新弹幕，不增加密度/速度设置。

界面打磨：快捷菜单默认焦点在最后的关闭/开启项，两菜单共享8dp垂直间距；设置框上限640dp、24dp内边距与组间距，标题与选项分组留白，来源芯片上限288dp/两行，水平24dp间隔、两侧20dp缩放留白。删除已加载详情行，搜索按钮居中。详情页以非焦点小标签显示“去广告”“弹幕”：前者表示四源已知素材过滤能力，不保证全站无广告；后者表示可接外部弹幕，不保证每部作品有数据。

关闭图标使用 Google Material Symbols Rounded 的 `subtitles_off`，与开启图标成对；Apache-2.0。视觉整理参考 unslop（Damir Sokolovsky，https://x.com/heydamir，CC BY 4.0），延用项目现有 TV Material 3 风格。

设置布局更新：弹窗上限760dp、40dp内边距；API地址右侧“保存”仅持久化地址，作品名称右侧“匹配”才查询弹幕。来源每行一条、与输入框左边缘对齐，保留原生焦点缩放空间。详情页只对支持过滤的来源显示 Google Material Symbols Rounded `ad_off` 图标（Apache-2.0），不再显示弹幕或文字能力标签。图标表示已知广告过滤能力，不是全站无广告保证。
